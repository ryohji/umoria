## わかったこと

- **死んだ人物のファイルを読むと、人物の記録は読まない。** `get_char()` は旗の語の死のビットが
  立っていると、モンスターの記憶と選択肢だけを戻して閉じる（`save.c:633` の `if ((l & 0x80000000L) == 0)`）。
  往復は生きている人物でしか意味がない。
- **書く得点と読む得点は別のもの。** 書くのは `total_points()` の答え、読むと
  `set_best_score_so_far()` に入る。往復では最高点を別に見た。
- 生きている人物の死因は、読んだあと `get_char()` が `"(alive and well)"` に書きかえる。
